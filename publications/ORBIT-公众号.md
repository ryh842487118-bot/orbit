# 打开这个网页，去宇宙里逛一会儿

如果给你一个可以随便逛的宇宙，你会先去哪里？

看看土星环，靠近太阳，还是把镜头一直拉远，看看银河系之外？

最近想分享一个小项目，叫 **ORBIT**。打开浏览器，就能从地球出发，自己控制视角，一路逛到太阳系、银河和本星系群。

先放一段实际网页录制的视频，25 秒就能大致知道它是什么样。

[![ORBIT 宇宙漫游演示，点击观看视频](https://raw.githubusercontent.com/ryh842487118-bot/orbit/main/demo-preview.jpg)](https://github.com/ryh842487118-bot/orbit/raw/refs/heads/main/demo.mp4)

[点击观看演示视频](https://github.com/ryh842487118-bot/orbit/raw/refs/heads/main/demo.mp4)

视频里镜头会带着你走，自己打开网页以后，就可以在喜欢的地方多停一会儿。鼠标拖动换角度，滚轮拉近拉远，点一下天体，镜头就会飞过去。

有几个画面，很值得单独拿出来看看。

**太阳系换个参照，轨迹就变了**

打开“运动轨迹”，太阳和八大行星会在身后留下不同颜色的线条。在银河参照下，行星绕着太阳运动，同时整个太阳系向前移动，线条就这样一圈圈向后延伸。

![银河参照下，太阳与八大行星向前延伸的运动轨迹示意](https://raw.githubusercontent.com/ryh842487118-bot/orbit/main/docs/previews/motion-galactic.jpg)

再切到太阳参照，镜头跟着太阳走，看到的就变成了熟悉的环绕轨道。

![太阳参照下，八大行星环绕太阳的轨迹示意](https://raw.githubusercontent.com/ryh842487118-bot/orbit/main/docs/previews/motion-solar.jpg)

这两张图适合来回对着看。同一组天体，只是换了参照，运动的样子就很不一样。网页里还可以暂停、调节演示速度，转到侧面或上方观察。

这里的轨迹是经过比例和时间调整的局部示意，方便理解运动关系，并不是太阳系真实航线的精确复刻。

**逛远了，也可以回来看看地球**

“感知地球”这个模式，把天气、闪电和台风图层放到了同一颗地球上。

夜晚的城市灯光还亮着，海面上能看到旋转的云带。点开事件，可以查看对应位置、数据来源和时间，也可以从左侧列表直接飞过去。

![感知地球模式：地球夜景与天气、闪电、台风图层](https://raw.githubusercontent.com/ryh842487118-bot/orbit/main/docs/previews/earthsense.jpg)

它用公开数据来驱动画面：天气来自采样点，台风信息来自公开事件源。云雨效果是视觉表达，独立闪电图层中也有标明的模拟点。看具体情况时，可以点开详情读来源记录。

比起只看一排天气数字，这种方式多了点空间感：某个天气事件究竟发生在地球的哪里，转过去就能看到。

**再往外走，看看不熟悉的名字**

除了太阳系里常见的行星，ORBIT 也收录了一些更远的恒星。

比如下面这颗 R136a1。画面里是一大团明亮的蓝白色，边缘泛着光，左侧可以读到它的简单介绍。天体真实存在，近景外观则是艺术化呈现。

![大麦哲伦星云中的 R136a1，恒星外观为艺术示意](https://raw.githubusercontent.com/ryh842487118-bot/orbit/main/docs/previews/massive-star.jpg)

还有这颗带着粉紫色条纹的“麦哲伦巨行星”。它是为漫游场景创作的虚构行星，页面直接写明了“创作示意”和“未确认存在”。

![粉紫色的麦哲伦巨行星，为虚构创作示意](https://raw.githubusercontent.com/ryh842487118-bot/orbit/main/docs/previews/extragalactic-planet.jpg)

这种地方可以单纯看画面，也可以顺手读一下旁边的介绍。遇到没听过的名字，再去查查它是什么，逛着逛着就多认识了一颗星。

最后，把镜头拉到本星系群。

银河系、仙女座星系、三角座星系和大小麦哲伦星云一起出现在视野里。刚才还占满屏幕的天体，这时候已经找不到了，得重新选中目的地才能回去。

![本星系群全景，星系结构与距离为示意，截图为此前版本](https://raw.githubusercontent.com/ryh842487118-bot/orbit/main/docs/previews/local-group.jpg)

这张是此前版本的截图，图里开放了五座星系，当前版本已经扩展到八座。星系的大小和间距做过视觉调整，方便在网页里来回探索。

**打开就能玩**

不需要安装软件。电脑上用鼠标拖动和滚轮缩放，手机上可以单指旋转、双指缩放。第一次打开，先点地球，再去土星，然后把视角拉远，就能熟悉操作。

源码也放在了 GitHub 上，用 Three.js 做的。对网页 3D 感兴趣的话，可以看看它是怎么把这些场景做出来的。

有空可以打开逛几分钟。不用提前想好路线，看到哪颗星顺眼，就点过去看看。
